# 🌱 오늘의 감사일기 (Today's Gratitude)

> **"오늘 하루, 고마웠던 순간을 찾아보세요."**  
> 학생들이 매일 감사한 일을 3가지씩 기록하고, AI의 따뜻하고 긍정적인 격려 코멘트를 받으며, 선생님은 학급 학생들의 감사일기 작성 현황과 일기를 날짜별/학생별로 편리하게 확인하고 지도할 수 있는 **학교 맞춤형 디지털 감사 습관 웹 애플리케이션**입니다.

---

## 🌟 주요 기능 및 화면 구성

### 👧 1. 학생 화면 (감사일기 쓰기)
- **따뜻한 파스텔톤 & 둥근 카드 UI**: 부드러운 세이지 그린, 코랄, 크림색으로 편안하고 포근한 심리적 안정감 제공
- **간편 로그인 및 다중 사용자 배려**:
  - 학년(1~3학년), 반(1~2반), 번호(1~25번), 이름 드롭다운 선택
  - 마지막 입력 정보 자동 기억
  - 컴퓨터실 등 공용 기기 사용을 고려한 직관적인 **[학생 변경 / 로그아웃]** 기능
- **오늘의 생각 질문 & 영감 문구**:
  - 매일 다른 성찰 질문(친구, 배움, 도움, 칭찬, 자연, 음식 등) 및 새로고침 지원
  - 영감을 주는 감사 명언 랜덤 큐레이션
- **상호작용 월간 달력**:
  - 이번 달 날짜 그리드 및 작성 상태 시각화 (작성한 날: 초록 새싹 `✓` 뱃지, 오늘 날짜 강조)
  - 날짜 클릭 시 해당 일자의 감사일기 작성 및 조회 창 오픈
- **3가지 감사일기 작성 및 수정**:
  - ① 오늘 감사했던 일은 무엇인가요?
  - ② 또 어떤 일에 감사했나요?
  - ③ 마지막으로 감사한 일은 무엇인가요?
  - 💡 친절한 감사 예시 가이드 제공
  - 날짜별 중복 작성 방지 (`studentId + date` 고유키) 및 수정 이력(`firstModifiedAt`, `updatedAt`) 보관
  - 저장 완료 시 폭죽(Confetti) 축하 인터랙션 연출
- **AI 따뜻한 격려 코멘트**:
  - 학생의 글을 평가하거나 점수 매기지 않고, 감사의 의미를 긍정적으로 지지하는 1~2문장의 온화한 피드백
  - 6대 감사 키워드 자동 분류 (`#친구`, `#가족`, `#학교·일상`, `#선생님`, `#배움·성장`, `#나 자신`)
  - 위기/고충 감지 시 공감과 함께 믿을 수 있는 선생님과의 대화를 따뜻하게 안내하는 안전 지원 장치 내장
- **부담 없는 자기성찰 통계**:
  - 이번 달 작성일(🌱), 기록한 감사 수(💚), 연속 작성 일수(🔥) 제공 (타인과의 순위 경쟁이나 점수 배제)

---

### 👩‍🏫 2. 교사 전용 대시보드 (학급 일기 모니터링 및 지도)
- **접근 권한 분리**: 교사 전용 PIN 비밀번호 인증 시스템 (기본 PIN: `1234`, 설정에서 변경 가능)
- **한눈에 보는 학급 작성 통계**:
  - 학년/반 필터 및 기준 날짜 선택 (오늘, ◀, ▶, 달력 선택)
  - 전체 학생 수, 작성 완료 수, 미작성 수, 오늘 작성률(%), 이달의 평균 작성일 요약 카드
  - 미작성 학생에 대한 중립적이고 편안한 표시 (빨간색 경고나 낙인 지양)
- **날짜별 학생 명단 & 실시간 검색**:
  - 출석 번호순 정렬, 작성 여부 뱃지, 감사 키워드 미리보기
  - 상태별 필터(전체 / 완료 / 미작성) 및 이름/번호 검색
- **학생 일기 상세 확인 & 교사 비공개 지도 메모**:
  - 3가지 감사 내용 전문 및 AI 코멘트 확인
  - **교사 전용 비공개 상담 지도 메모** (`teacher_notes`) 작성 및 영구 보관 (학생에게 절대 비공개)
- **학급 월간 작성률 달력**:
  - 한 달 동안 학급의 일자별 작성률(예: 9월 1일 92%, 9월 2일 88%...)을 시각적 히트맵으로 제공
  - 날짜를 클릭하면 해당 일자 학생 명단으로 즉시 이동
- **학생별 누적 일기 이력**:
  - 특정 학생을 선택하면 해당 학생의 한 달 치 작성 달력과 작성일을 한 번에 확인
- **엑셀/CSV 데이터 관리**:
  - **학생 명단 일괄 등록**: 엑셀/CSV 파일(번호, 이름) 업로드 시 학급 학생 목록 자동 생성
  - **감사일기 엑셀 다운로드**: 날짜, 학년, 반, 번호, 이름, 감사 1~3, AI 코멘트, 키워드, (선택) 교사 메모 포함 다운로드
- **관리자 설정 & 시연용 샘플 데이터**:
  - 1-클릭 샘플 데이터 채우기 (25명 학생 및 작성 일기 즉시 생성)
  - 새 학기 데이터 전체 초기화 기능
  - Supabase 클라우드 연동 및 SQL 테이블 생성 스크립트 제공

## 🚀 실행 및 배포 방법

### 방법 1. 깃허브(GitHub) 테스트 및 GitHub Pages 배포 ⭐
1. 이 프로젝트 저장소를 깃허브(GitHub)에 업로드(Push)합니다. (`node_modules`는 `.gitignore`에 의해 자동 제외됩니다.)
2. 깃허브 저장소 상단 **Settings ➔ Pages**로 이동합니다.
3. **Build and deployment**의 Source를 **Deploy from a branch**로 두고, Branch를 **`main` / `/(root)`**로 선택한 뒤 **Save**를 누릅니다.
4. 1~2분 후 생성되는 주소(`https://[아이디].github.io/[저장소명]`)로 접속하면 전 세계 어디서든 웹으로 바로 테스트할 수 있습니다!

### 방법 2. Firebase 호스팅 배포 (언제 어디서나 접속 & 클라우드 실시간 동기화)
1. 프로젝트 폴더 내 **`배포하기_firebase.bat`** 파일을 더블 클릭하여 실행합니다.
2. 구글 로그인 및 호스팅 배포가 완료되면 발급된 주소(`https://todays-gratitude.web.app`)로 학생들이 즉시 일기를 작성할 수 있습니다.

### 방법 3. 내 컴퓨터에서 바로 실행 (오프라인/로컬)
* 폴더 내 **`오늘의감사_실행.bat`** 또는 **`index.html`** 파일을 더블 클릭하시면 웹 브라우저에서 프로그램이 즉시 실행됩니다.

todays-gratitude/

├── package.json            # [필수] 프로젝트 의존성 및 스크립트 정의
├── package-lock.json       # [필수] 패키지 버전 잠금 파일
├── tsconfig.json           # [필수] TypeScript 컴파일 설정
├── vite.config.ts          # [필수] Vite 빌드 설정
├── tailwind.config.js      # [필수] Tailwind CSS 스타일링 설정
├── postcss.config.js       # [필수] PostCSS 설정
├── README.md               # [필수] 프로젝트 설명 문서
├── FIREBASE_안내.md        # [참고] Firebase 콘솔 설정 가이드
├── 배포하기_firebase.bat   # [도구] 원클릭 Firebase 배포 스크립트
├── 오늘의감사_실행.bat      # [도구] 로컬 단독 실행 스크립트
└── src/                    # [필수] React + TypeScript 모듈형 소스코드
    ├── components/         # 학생/교사/공통 UI 컴포넌트

    ├── types/              # TypeScript 인터페이스 정의
    └── utils/              # 문장 검증기, 키워드 추출기, 날짜 유틸

## 🛠️ 기술 스택 및 아키텍처

- **Frontend Framework**: React 18 (TypeScript)
- **Build Tool**: Vite 5
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti
- **Excel/CSV Engine**: SheetJS (`xlsx`)
- **Storage Architecture**: `IStorageService` 추상화 어댑터 패턴
  - 기본: 브라우저 `localStorage` (100% 오프라인, 즉시 구동)
  - 확장: `SupabaseStorageService` (학교 컴퓨터실-교무실 실시간 클라우드 연동 지원)
- **AI Architecture**:
  - 기본: 내장 룰 & 키워드 분석 기반 온화한 격려 엔진 (네트워크 없이 100% 안전)
  - 확장: OpenAI (GPT-4o) / Google Gemini API 연동 인터페이스 구비

## 🔒 개인정보 보호 및 AI 원칙

1. **학생 정보 최소화**: 학년, 반, 번호, 이름 외에 불필요한 개인 식별 정보를 요구하지 않습니다.
2. **학생과 교사 화면 분리**: 학생은 본인의 일기만 볼 수 있으며, 교사는 전용 PIN 인증을 거쳐 학급 대시보드에 접근합니다.
3. **교사 메모의 비공개성**: 교사가 작성한 관찰 메모는 교사 화면에서만 조회되며 학생 화면에 절대 노출되지 않습니다.
4. **AI의 역할**: AI는 학생을 평가하거나 점수 매기지 않으며, 학생이 찾은 감사의 의미를 지지하고 공감하는 1~2문장의 따뜻한 격려자 역할만 수행합니다.
